[`../orchestrator-prompt.md`](../orchestrator-prompt.md) will live — a plan

Writing those assets and running the proof are their own piece of work, out
of scope for the documentation this placeholder belongs to

that work lands, nothing here has run, and

than borrowing the earlier proof's result.
